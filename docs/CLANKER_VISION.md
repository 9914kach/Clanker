# Clanker Vision

## Overview

Clanker is not meant to be a corporate dashboard, a sterile admin panel, or a generic community tool.
It is a fun, expressive, personality-driven community site for the Discord server **Neutralen**.

The goal is to build a shared digital place for the community that mixes:

- genuinely useful tools
- pointless but hilarious features
- internal lore, memes, quotes, and callbacks
- expressive GUI/UX with warmth, emotion, humor, and identity
- playful realtime interactions between members

Clanker should feel less like a normal website and more like a **community OS**, **social toybox**, and **living digital hangout** for the server.

---

## Core Product Direction

### What Clanker is

Clanker should be:

- a digital home for Neutralen
- a place that preserves and amplifies server culture
- a mix of useful and useless in the best possible way
- interactive, reactive, playful, and social
- emotionally expressive rather than clinically polished
- charming, slightly chaotic, and memorable

### What Clanker is not

Clanker should **not** be:

- AIK-specific
- corporate
- sterile
- generic
- optimized only for efficiency and cleanliness
- a fake productivity tool
- a standard SaaS dashboard with community data pasted into it

---

## Core Philosophy

The most important guiding thought:

> Do not just ask "what features should exist?"
> Ask: **what in our Discord culture should be preserved, amplified, and made more fun?**

That is where the soul of the project lives.

Clanker should feel like a **love letter to the community**, not a product for customers.

---

## Product Pillars

Clanker should be built on three major layers:

### 1. Useful
Features people actually use because they solve real community problems.

Examples:

- link collection and link hub
- quotes archive
- polls and decisions
- event planning
- wheel/randomizer tools
- community dashboards

### 2. Social
Features that make members feel present, visible, and connected.

Examples:

- custom profiles
- profile themes
- badges and titles
- status and presence
- shared widgets
- leaderboards
- member identity systems

### 3. Chaos
Features that are not necessary, but make the site unforgettable.

Examples:

- pranks
- easter eggs
- sound effects
- cursed widgets
- meme drops
- absurd notifications
- hidden commands
- playful UI sabotage used sparingly

The magic is not in choosing one of these.
The magic is in combining all three.

## Design Philosophy

### Primary Rule

**Optimize for character, not maximum cleanliness.**

A perfectly clean interface is not the goal.
A memorable and emotionally rich interface is.

### Design principles

1. **Personality before perfection**
2. **Charm before sterility**
3. **Feeling before corporate polish**
4. **Interactivity before passiveness**
5. **Community identity before generic UX**
6. **Stable technical foundation underneath expressive chaos**

### What that means in practice

- copy should sound human, funny, or dramatic where appropriate
- empty states should have personality
- success states can be over-celebratory
- errors can be playful instead of cold
- loading can feel like the system is thinking or booting
- buttons and widgets can have subtle attitude
- small imperfections can add life
- visuals should feel designed, not template-generated

### What to avoid

- generic gray dashboard layouts
- lifeless cards with too much enterprise polish
- B2B-feeling typography and spacing everywhere
- default component-library look without customization
- over-minimalism that removes emotional texture

## GUI / UX Identity

Clanker should have a GUI/UX language with charm, personality, and emotion.

The interface should not feel like it came from a startup template.
It should feel like an expressive, playful system with its own identity.

### Important traits

- warm and animated
- opinionated microcopy
- visual feedback with character
- recurring visual and motion patterns
- memorable interactions
- internal jokes embedded in interface details

### Strong UX concept

Each meaningful page should ideally contain a blend of:

- something useful
- something social
- something charming
- something slightly absurd

That combination helps every page feel like part of the same world.

## Living Site Layer

A major part of Clanker's identity is that the site should feel **alive**.

This includes:

- rotating live text
- animated widgets
- subtle motion throughout the interface
- reactive hover states
- sound effects
- rare random events
- dynamic copy
- systems that behave differently depending on time, context, or randomness

### Example ideas

- rotating live text from quotes, statuses, memes, fake headlines, cursed observations, or input data
- "quote of the day"
- "today's sinner"
- a widget that changes tone depending on the hour
- panels that subtly react to clicks or movement
- small celebration effects for completely unnecessary actions

---

## Humor and Chaos Layer

This is one of the most important differentiators.

Clanker should not only contain community data.
It should actively support humor.

### Humor systems to include

- memes integrated into UI
- playful notifications
- joke actions in context menus
- absurd stats and titles
- fake warnings or dramatic system messages used sparingly
- cursed modes or special events
- internal references only members understand

### Frequency model

To avoid becoming annoying, these should exist at three levels:

#### Always on
Subtle charm that is present all the time.

Examples:
- microanimations
- rotating text
- hover reactions
- playful wording
- small system sounds

#### Sometimes
Things that appear occasionally to keep the site fresh.

Examples:
- rare memes
- special tooltips
- surprise notification variants
- occasional UI jokes

#### Rare
High-impact surprises that should stay special.

Examples:
- pranks
- cursed mode
- hidden routes
- secret interactions
- fake ban/pop-up jokes
- special date/time events

## Core Feature Directions

## 1. Hall of Fame / Lore Archive
A permanent place for:

- legendary quotes
- iconic screenshots
- classic moments
- community memes
- notable events
- cursed history

Discord is bad at preserving lore.
Clanker can become the memory of the server.

## 2. Link Hub
A genuinely useful feature and likely one of the strongest early wins.

Possible functions:

- collect links posted in Discord
- deduplicate them
- store preview/title/source/user/date
- tag them by category
- upvote or save favorites
- surface "weekly best links"
- show most shared / most cursed links

## 3. Quotes / Neutralen Says
A quote module should be central.

Possible functions:

- save quotes
- attribute them to members
- vote on them
- randomize them
- feature a quote of the day
- track the most quotable members

## 4. Polls / Decision Tools
Fast, community-centered, fun, practical.

Examples:

- what should we play tonight
- who is late
- which clip wins
- who deserves blame today

## 5. Wheels / Randomizers / Chaos Tools
A major fit for the project.

Examples:

- punishment wheel
- team randomizer
- challenge generator
- what-should-we-do wheel
- cursed fate spinner

This is also a perfect area for realtime multiplayer.

## 6. Profiles / Identity
Users should be able to build a playful identity inside the system.

Examples:

- custom profile themes
- profile colors
- badges
- titles
- aura/status/alignment
- cosmetic effects
- profile messages or taglines

## 7. Leaderboards / Stats
Not only serious stats.
Funny, semi-fake, and ironic stats are just as important.

Examples:

- most quoted
- most links posted
- latest night owl
- most chaotic aura
- biggest cope artist
- weekly goblin

## Community OS Direction

One of the strongest concepts discussed is making Clanker feel like a kind of **OS-lite** or **community operating system**.

Not a literal OS.
Not a Windows clone.
But a site that feels like its own program, world, and interface system.

### What creates that feeling

- taskbar or dock
- widgets or small apps
- right-click context menus
- system-style notifications
- overlays and drawers
- panels that feel like movable or openable modules
- command palette
- little "system" feedback sounds
- shared interface metaphors across the whole site

### Important note

Do **not** make a fake Windows desktop.
Instead, create a **Neutralen OS** with its own style and internal logic.

### Example interactions

Right-clicking a profile might show:

- view profile
- add quote
- assign aura
- accuse
- crown as goblin

Right-clicking a link might show:

- save to lore
- mark as cursed
- repost
- nominate for weekly gold

Right-clicking the desktop/dashboard might show:

- change theme
- spawn widget
- chaos mode
- open command bar

## Realtime / Multiplayer Direction

Clanker should eventually feel multiplayer.
Not just a site where many people log in separately, but a place where people can interact with shared objects live.

### Example shared interactions

- several users editing the same wheel at once
- live poll updates
- shared widget changes
- collaborative boards or lists
- visible user presence in tools
- light social multiplayer features inside modules

### Key conclusion

This is fully possible within the current codebase direction.
It does **not** require rebuilding the entire project from scratch.

### Technical direction

- keep the current monorepo structure
- keep the current web/API split
- add an app-shell on the frontend
- add realtime shared-state where it matters
- use WebSockets for live events
- persist durable state in the database
- start with one shared object as proof of concept

### Best first realtime proof of concept

A shared collaborative wheel.

Example live events:

- add item
- remove item
- rename entry
- change theme
- start spin
- stop spin
- show presence of connected members

The wheel is a perfect first multiplayer module because it is fun, clear, visual, and immediately demoable.

---

## Technical Product Strategy

### Near-term strategy

1. Build the **feel** first.
2. Add the **community OS shell**.
3. Implement one or two strong core modules.
4. Add subtle charm layers.
5. Add one realtime collaborative feature.
6. Expand gradually.

### Why this is the right order

Because Clanker's value is not only feature count.
It is the combination of:

- identity
- charm
- community-specific humor
- social presence
- interaction quality

If the emotional and aesthetic direction is right early, the rest of the system becomes much easier to extend coherently.
